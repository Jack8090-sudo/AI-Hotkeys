# S13b: Manifest-driven uninstall, Ollama checks, metadata

Fixes **C08**, **C29** (installer wiring), **C30**, **C31**, **C44** and **C45**. Implements **D4**
and the installer side of **D5**.

Files changed: `installer/sorgente/installer.nsi` and `installer/sorgente/stop.ps1`. New:
`installer/sorgente/ollama-check.ps1`, a helper next to `stop.ps1`; `build.ps1` already stages every
`*.ps1`. It builds on `manifest.ps1` from S13a.

## C08 / C30: manifest-driven install, upgrade and uninstall

- **Uninstall list.** `!include "uninstall.nsh"` (generated by `build.ps1`) is used with
  `!insertmacro AIH_UNINSTALL_PAYLOAD` instead of the hand-written list. It removes every payload file
  except `config.ini`, including the whole `searxng\` tree and `config.example.ini` (the ~82 MB C08
  leftover), the `__pycache__` folders and then the folders left empty. The uninstaller also deletes
  `.manifest` and `Uninstall.exe`.
- **`$INSTDIR\.manifest`.** It is copied from the embedded build `manifest.txt` after all files are
  extracted.
- **Upgrade.** When `.manifest` exists, the installer runs `manifest.ps1 -Action Upgrade`. That step:
  - backs up a customized `prompts.py` (D4)
  - deletes the files in the old manifest that are missing from the new one, then the folders this
    empties
  - purges every `__pycache__` folder except `work\`

  Without a `.manifest`, the v1.0.0 path from S13a applies.
- **Protected files.** `config.ini`, `work\`, `prompts_user.py`, `prompts.local.py`, `prompts.py.bak-*`
  and `*.backup*` are never removed by the upgrade or the default uninstall.
- **D4.**
  - `prompts.py` is saved as `prompts.py.bak-<oldver>` when its hash matches neither the previous
    release's shipped hash (from the old `.manifest`, or the legacy manifest for v1.0.0) nor the new
    one.
  - `<oldver>` comes from the registry `DisplayVersion`, or else the old manifest's header. Existing
    identical backups are reused, and different ones get a `-2`, `-3`, … suffix.
  - Migration from another folder does the same: the old folder's customized `prompts.py` is saved
    into the new folder.
- **Uninstall and the registered installation.** Shortcuts and registry keys are removed only when the
  registry's `InstallDir` is this folder, or empty. An uninstaller left in another folder cannot
  unregister the live installation. Start-menu shortcuts are deleted by name, and the folder is
  removed only if it is empty.

## C45: stop.ps1 and /PURGE

- **`stop.ps1 -Dir <folder>`** stops three kinds of process:
  - executables under `<Dir>\python\` or `<Dir>\ahk\`, matched with a trailing separator, so
    `C:\AI-Hotkeys` no longer matches `C:\AI-Hotkeys2`
  - AutoHotkey running `<Dir>\main.ahk`
  - any `python*.exe` whose command line references `<Dir>\`, i.e. SearXNG, the viewer or settings
    under a system Python
- It skips itself and its parent. It waits up to 5 s for the processes to exit. It refuses drive roots.
- **Exit codes:** 0 nothing left running, 1 still running, 2 bad `-Dir`, 3 process list unreadable.
- On 1, install and uninstall show Retry/Cancel. In silent mode they cancel with error level 2 instead
  of overwriting files that are in use. Code 3 only logs a warning.
- **`Uninstall.exe /PURGE`** deletes `config.ini` and `work\` without asking. A plain `/S` uninstall
  keeps them. The interactive uninstall still asks, and now says that `prompts_user.py` and
  `prompts.py.bak-*` are kept either way. `/PURGE` keeps those two as well (see "Left open").

## C31 / C44: Ollama

- **`/NOOLLAMA`** (`${GetOptions}` in `.onInit`) unselects the Ollama section, and the section also
  checks the flag.
- **Silent installs never open a browser and never run winget.** If Ollama is missing they only log
  the download URL.
- **winget.**
  - It is offered only if `%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe` exists, and it runs by
    that full path.
  - The question says that installing this way "accepts the Ollama/winget source and package terms".
    The buttons are Yes = winget, No = download page, Cancel = skip.
  - Without winget, the installer only offers the download page.
  - winget's exit code is checked. A failure, or no `ollama.exe` afterwards, is reported and the
    download page opens (interactive only).
- **Detection.**
  - Known paths first: `$LOCALAPPDATA\Programs\Ollama`, `$PROGRAMFILES64\Ollama`, `$PROGRAMFILES\Ollama`.
  - Then `"$SYSDIR\where.exe" ollama.exe`, run with `SetOutPath $SYSDIR` so the working directory is
    never the installer's folder. The previous output path is restored afterwards.
- **Model check (`ollama-check.ps1`).**
  - It uses the model from `config.ini [qwen] model`; the default is `qwen3.5:9b`.
  - It first looks for the manifest file
    `%OLLAMA_MODELS%` or `%USERPROFILE%\.ollama\models\manifests\registry.ollama.ai\<ns>\<name>\<tag>`.
  - Then it calls `GET http://127.0.0.1:11434/api/tags`, with no proxy and a 3 s timeout.
  - Exit codes: 0 present, 10 "server running, model missing", 11 "server not running and no manifest
    on disk", 2 bad name. Each case gets its own message, so a stopped server is no longer reported as
    "model missing".

## C29: license and metadata

- **License page.** `MUI_PAGE_LICENSE "payload\app\LICENSE"` (MIT), with a Next button and no
  acceptance checkbox. The bottom text points to `THIRD_PARTY_NOTICES.md` and `licenses\`.
- **License files.** The payload already contains `LICENSE`, `THIRD_PARTY_NOTICES.md` and `licenses\`
  (S11 allowlist, verified in `build\out\payload\app`). `File /r payload\app\*.*` installs them, and
  the generated uninstall list removes them.
- **Version info.**
  - `LegalCopyright` is "© 2026 AI-Hotkeys contributors — MIT".
  - `VIProductVersion` is `${VERSION}.0`, and `ProductVersion` is `${VERSION}`.
  - `CompanyName` and the registry `Publisher` are "AI-Hotkeys contributors".
- **Uninstall registry key.**
  - `URLInfoAbout` and `HelpLink` are `https://github.com/Jack8090-sudo/AI-Hotkeys`.
  - `QuietUninstallString` is `"<dir>\Uninstall.exe" /S`.
  - `EstimatedSize` is the install folder's real size in KB (`${GetSize}`).

## Finish page

`MUI_FINISHPAGE_TEXT_LARGE` gives the text more room, and it stays under NSIS's 1024-character string
limit (653 characters). It covers:
- the keys
- `ollama pull qwen3.5:9b` (6.6 GB) and the VRAM guidance: about 8 GB free, otherwise it spills into
  RAM and becomes much slower; tray → Free VRAM
- the D5 disclosure: End may send search terms taken from the selection to public search engines
  through the local SearXNG, and it can be turned off in Settings
- where the Obsidian settings live: tray ✦ → Settings, or `config.ini`
