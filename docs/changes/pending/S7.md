# S7 — Local servers, config writer and page security

User-visible:
- Results and settings pages send a Content-Security-Policy. Remote images in answers are never
  loaded: they are shown as a link "Image: <name>" (decision D8). Checked in a browser: markdown,
  code blocks, fonts and follow-ups still work, no request leaves 127.0.0.1.
- The secret token is removed from the address bar after the page loads (pressing F5 then shows
  the page as disconnected: reopen it from the hotkey).
- Saving an Ollama URL that points to another computer still works but returns a warning
  ("the text you select will be sent there"); the settings page shows it after S10.
- Follow-up answers interrupted by Ollama are reported as incomplete ("partial") instead of being
  saved as complete.

Internal:
- pages.token_ok (no crash on non-ASCII tokens), pages.LocalServer (errors -> work/server.log,
  capped at 1 MB), 30 s request timeout, monotonic idle timers (H19).
- settings: fullmatch validators (C36), ASCII-only numbers (C35).
- config_edit: atomic save, rejects line breaks and invalid names, understands "key: value",
  splits lines only on real line breaks (C17).
- viewer uses prompt_loader (prompts_user.py, D4).
- C21 (404 shown as "Cannot reach Ollama" in follow-ups) stays for S9.
