# S5 — Obsidian To-Do data safety

User-visible:
- Backups now go to the hidden folder ".ai-hotkeys-backups" next to the To-Do file
  (Obsidian does not index dot-folders, so tasks and tags are no longer duplicated in search).
  The newest 20 are kept. Old "To-Do List.backup_*.md" files next to the note are never touched.
- A UTF-8 BOM in the To-Do file is preserved (CRLF/LF already was).
- Every failure now writes "ERRORE" with a reason (no more "No result."): unreadable/non-UTF-8 file,
  file locked (5 retries), unexpected errors. The original file is never modified on failure.
- Extra safety checks: frontmatter / text before "# 🟢" must be unchanged; paragraphs, table rows and
  headings may not disappear; a task rewritten into something unrelated is rejected.
- Qwen's copy (work/obsidian_output.txt) is deleted after a successful update, kept when a check fails.

Deviation from the plan (recorded): task similarity threshold is 0.3, not 0.6. The prompt asks Qwen
to translate English tasks into Italian; translations measure about 0.36, unrelated text about 0.2.
0.6 would have blocked the translation feature (behaviour to preserve).
